# Contributing

This repository accepts focused corrections to public ChartUp product information.

Appropriate contributions include fixing links, clarifying Solana or BNB terminology, improving accessibility, and updating claims that can be verified through a ChartUp-controlled source.

Do not add financial promises, unsupported rankings, fabricated metrics, private user information, or instructions that conflict with ChartUp's current terms.

For a pull request, explain the correction, identify the affected section, and link the official source supporting the change. Confirm that formatting and links work before submission.
