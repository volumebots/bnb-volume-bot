# Security Policy

This repository contains product information rather than executable ChartUp software. Reports may still concern impersonation, unsafe links, copied bot identities, or a security issue observed in an official hosted product.

## Report a Concern

Contact [`@chartup_support`](https://t.me/chartup_support) with the affected network, official bot username, approximate time, public transaction details, and a concise description. Remove private or identifying information from screenshots.

Do not publish details that could enable exploitation before the issue has been reviewed.

## Protected Information

Never share:

- Private keys or seed phrases
- Telegram login codes
- Passwords or authentication tokens
- Exchange or brokerage credentials
- Unnecessary personal information

ChartUp's documented order workflow does not require wallet recovery credentials.

## Verify Before Acting

Use the [ChartUp website](https://www.chartup.io/), [official GitBook](https://chartup.gitbook.io/docs), or documented channel addresses to verify an account. A familiar avatar or display name is not sufficient.
