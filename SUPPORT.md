# Support

Official ChartUp support is available at [`@chartup_support`](https://t.me/chartup_support).

## Include These Details

- Solana or BNB Smart Chain
- The exact official bot username
- Contract address and relevant venue
- Task or order identifier
- Approximate start time
- Public transaction hashes
- Expected result and observed behavior

Do not include private keys, seed phrases, login codes, passwords, or unrelated personal data.

## Repository Issues

Use GitHub Issues for broken links, unclear wording, incorrect public information, or accessibility problems. Use Telegram support for payments, active orders, or information tied to an account.
